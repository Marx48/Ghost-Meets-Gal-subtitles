# 👻 Ghost Meets Gal! - English Subtitles

This repository contains unofficial fan-made **English subtitles** for the mini-anime **Ghost Meets Gal!**, a *Cardfight!! Vanguard* spin-off centered on two girls aiming to become idols.

Since the episodes are short (around 2 minutes) and lacked English subtitles, I decided to create them so the community can enjoy the series.

---

## 📂 Available Files

Subtitles are provided in the `.ass` format (Advanced Substation Alpha) with custom styling, compatible with most media players.

- `Ghost Meets Gal Ep01 eng sub.ass` — Episode 01

*(Subtitles will be updated as new episodes are released!)*

---

## 🛠️ How to Use

You can use these subtitles in two simple ways:

### Option 1: Automatic Loading (VLC, MPC-HC, mpv, etc.)
1. Download the video file and the corresponding subtitle file (`.ass`) from this repository.
2. Ensure both the **video and subtitle files have the exact same name** and are stored in the same folder (e.g., `Ghost_Meets_Gal_ep01.mp4` and `Ghost_Meets_Gal_ep01.ass`).
3. Open the video using your preferred media player (recommended: **VLC Media Player** or **mpv**). The subtitles will load automatically.

### Option 2: Drag and Drop
1. Open your video file in your media player.
2. Drag and drop the downloaded `.ass` subtitle file directly into the player window.
